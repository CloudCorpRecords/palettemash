# Art Sources & Credits — PaletteMash

**The short version: this project contains no artwork by anyone else — not
downloaded, not scraped, not photographed, not traced.** Every image in this
repository was generated at runtime by the code in `src/blend.js`. The three
built-in "source artworks" are original procedural renderings *inspired by*
public-domain works, credited here in full.

| Procedural study (generated by this code) | Inspiration (public domain) | Status of the inspiration |
|---|---|---|
| Swirl Night | *The Starry Night* (1889), Vincent van Gogh (1853–1890) | Public domain worldwide (artist died 1890) |
| Great Wave | *The Great Wave off Kanagawa* (c. 1831), Katsushika Hokusai (1760–1849) | Public domain worldwide (artist died 1849) |
| Grid Composition | *Compositions with Red, Blue and Yellow* (1930s), Piet Mondrian (1872–1944) | Public domain in the United States (artist died 1944) |

What "inspired by" means here, precisely:

- The generators (`paintSwirlNight`, `paintGreatWave`, `paintGridComposition`
  in `src/blend.js`) paint **original** compositions — spirals and star orbs,
  layered wave arcs and a mountain triangle, a primary-colour grid — using the
  *manner* of each master, not reproductions of any specific canvas.
- No image file of any of the named works (from Wikimedia Commons or anywhere
  else) is bundled in, linked to, or loaded by this project. An earlier design
  considered shipping Commons image files; the shipped design generates
  everything procedurally instead, which keeps the provenance claim absolute:
  the only thing that travels from "source" to output is **colour**, extracted
  from pixels this code itself painted.
- If a user adds their own photo in the web UI, it is processed entirely in
  their browser (palette extraction only) and is never uploaded or stored.

Output images in `output/` were produced by `node smoke-test.js` from the
generators above and are released under the same MIT licence as the code.
